# Contributing

Thanks for helping! Bug reports, docs and pull requests are welcome.

- Read [docs/development.md](docs/development.md) to get the app running locally. No AWS account is needed.
- Keep changes focused. Add or update tests, and run `npm run typecheck && npm test` before opening a pull request.
- UI strings need both English and German (`packages/web/src/i18n`).
- Contributions to everything outside `ee/` are licensed under Apache-2.0. Contributions to `ee/` are accepted under the terms in [ee/LICENSE](ee/LICENSE).
- For security issues, follow [SECURITY.md](SECURITY.md) instead of opening an issue.
